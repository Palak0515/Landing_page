# Hungry Bird - Food Landing Page

## Description

A simple food landing page created using HTML and CSS.

## Features

* Food-themed landing page
* Navigation bar
* Social media icons
* Animated elements
* "Order Now" button

## Technologies Used

* HTML
* CSS
* Font Awesome
* Animate.css
* jQuery

## Purpose

This project was created to practice fundamental frontend web development concepts, including HTML structure, CSS styling, positioning, animations, and integrating external libraries.

## How to Run

1. Clone or download this repository.
2. Open index.html in any modern web browser.
3. The landing page will load directly.
